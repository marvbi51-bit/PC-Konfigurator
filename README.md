# PC-Konfigurator

Grundlage: vorhandene V7 mit fünf Builds und Live-Aufbau. Dies ist ein unveränderter Import der bestehenden Webseite, keine neu entworfene Oberfläche.

## Lokal testen
`index.html` mit einem lokalen Webserver öffnen, zum Beispiel `python -m http.server 8000`, dann `http://localhost:8000` aufrufen.

## Nächste Schritte
1. Navigation und Bearbeiten-Schaltflächen im Browser testen.
2. Komponentenvergleich vor den Konfigurator stellen.
3. Preise und technische Angaben als Richtwerte kennzeichnen.
4. Erst danach Quellcode in Module aufteilen.

Keine automatische Veröffentlichung auf Netlify ohne Test und Freigabe.
